# Personal Homepage — Agent Guidelines

## Color Palette

- Primary accent (links, floating table-of-contents button, focus rings): Peking University red (北大红) `#94070A`; hover `#7A0508`, active `#5F0406`.
- Publication venue labels such as `[MM'26]` and the "Hire me" pill: Tailwind Red 600 (`#DC2626`).
- For interactive states, use a darker step of the same hue for hover and an even darker one for active.
