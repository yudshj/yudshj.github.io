# Personal Homepage — Agent Guidelines

## Color Palette

- Keep primary accent colors on the Tailwind CSS `600` scale for a consistent visual weight.
- Floating table-of-contents button: Tailwind Blue 600 (`#2563EB`).
- Publication venue labels such as `[MM'26]`: Tailwind Red 600 (`#DC2626`).
- For interactive states, use the corresponding `700` shade for hover and `800` shade for active when appropriate.
